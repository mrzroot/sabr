PROJECT WALKTHROUGH

Pick the correct resume strategy without confusing history and files.

  1. Repository interrupted

    Resume in the existing partial destination or rerun the same clone command. Do not delete the partial directory unless you intentionally want to start fresh.

    sabr resume ./your-checkout

  2. File interrupted

    Use the same URL and the known checksum from a trusted publisher. Range resume uses partial data; verify the final file before using it.

    sabr get URL --sha256 HEX

  3. Plan for offline history

    A regular clone prioritizes the latest checked-out files. If you need every historical file without a network later, request all blobs up front.

    sabr clone --all-blobs URL
راهنمای عملی پروژه

با توجه به نوع دانلود، روش درست ادامه‌دادن را انتخاب کنید.

  1. کلون قطع‌شده

    همان فرمان را تکرار کنید یا از مسیر مقصد قبلی ادامه دهید. اگر نمی‌خواهید از نو شروع کنید، پوشهٔ ناقص را پاک نکنید.

    sabr resume ./your-checkout

  2. دانلود فایل قطع‌شده

    همان نشانی و هش منتشرشده در منبع مطمئن را استفاده کنید و پیش از استفاده، فایل نهایی را راستی‌آزمایی کنید.

    sabr get URL --sha256 HEX

  3. تاریخچه برای استفادهٔ آفلاین

    کلون معمولی به فایل‌های نسخهٔ جاری اولویت می‌دهد؛ اگر همهٔ نسخه‌های تاریخی را آفلاین لازم دارید، همهٔ blobها را دریافت کنید.

    sabr clone --all-blobs URL
